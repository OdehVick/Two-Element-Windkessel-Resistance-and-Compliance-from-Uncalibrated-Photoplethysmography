# Archive

Scripts from earlier stages of the project. They are kept for transparency but
are **not** needed to reproduce any result in the article.

| Script | What it was |
|---|---|
| `run_vitaldb.py` | First EXP-A/EXP-B driver with a single-beat estimator; superseded by `code/run_spread.py` and `code/run_expb.py`. |
| `phe_discover.py` | Exploratory check of phenylephrine timing; not used in the article. |

They import the shared modules in `code/`; run them from that folder with `PYTHONPATH=. python ../archive/<script>.py`.
